## 🌷 关于 PetDesktop

**PetDesktop** 是一款面向 Windows 的桌面陪伴应用，希望将虚拟宠物、生活记录与日常管理自然地结合在一起，打造一个轻松、温暖且个性化的数字生活空间。

在这里，一只可爱的像素小猫会生活在你的电脑桌面上。

你可以抚摸它、喂食、陪它玩耍，观察它在不同状态下的反应。它会随着时间和互动改变行为，在你工作、学习或休息时安静地陪伴你。

双击小猫，还可以打开属于自己的生活空间。

你可以记录日记、整理待办事项、查看日历，以及回顾每天的心情。

而 PetDesktop 的长期目标，不只是提供一个可爱的桌面宠物。

未来，它还将结合 AI 对话能力，让你能够随时分享生活中的想法、心情和故事，并将值得收藏的聊天内容保存到日记与日历中。

**希望 PetDesktop 不只是一个工具，而是一个能陪伴你、帮助你记录生活的桌面伙伴。**

## 💭 设计理念

生活不只有待办事项。

还有突然出现的灵感、想要分享的故事、值得纪念的瞬间，以及那些容易被遗忘的小事。

传统的桌面宠物提供陪伴，日记应用帮助记录生活，任务管理工具则负责安排日常。

PetDesktop 希望将这些体验连接起来。

不需要在不同的软件之间频繁切换，也不必将聊天、日记和任务分散在多个地方。

打开电脑，就能看到熟悉的小猫。

想说话的时候，可以和它聊天。

想记录的时候，可以随手写下。

想整理生活的时候，可以打开日历和任务列表。

而过去记录的心情、故事与回忆，也能够随着时间逐渐积累。

**让陪伴、记录与日常管理，成为自然发生的事情。**

## 🛠️ 技术架构

PetDesktop 结合了 Python 原生桌面开发与 Web 前端技术。

桌面小猫由 PySide6 提供窗口、动画和交互管理。

手帐与生活管理页面则由 Qt WebEngine 加载 HTML、CSS 和 JavaScript 实现。

两部分通过 QWebChannel 进行通信。

### 技术栈

| 技术           | 用途                     |
| ------------ | ---------------------- |
| Python       | 应用核心逻辑                 |
| PySide6      | 桌面窗口、事件与交互             |
| Qt WebEngine | 加载和展示 Web UI           |
| QWebChannel  | Python 与 JavaScript 通信 |
| HTML         | 页面结构                   |
| CSS          | 页面样式与布局                |
| JavaScript   | 前端交互与页面逻辑              |
| JSON         | 本地日记、心情与桌宠数据           |
| localStorage | Home 任务清单存储            |
| PyInstaller  | Windows 应用打包           |

### 系统组成

PetDesktop 目前主要由两个部分组成。

**1. Desktop Pet · 桌宠系统**

负责：

* 桌宠窗口管理
* 动画状态切换
* 鼠标交互
* 桌宠移动与落地行为
* 情绪与需求值管理
* 桌宠状态保存
* 系统托盘交互

**2. Personal Workspace · 个人生活空间**

负责：

* Home 首页
* Diary 日记
* Calendar 日历
* Chat 对话界面
* Task 任务页面
* 页面交互
* 日记与心情数据读写

### 通信方式

应用使用 QWebChannel 连接 Python 后端与 JavaScript 前端。

```text
                  PetDesktop
                      │
          ┌───────────┴───────────┐
          │                       │
     Desktop Pet             Personal Workspace
          │                       │
       PySide6                Qt WebEngine
          │                       │
    桌宠行为与动画            HTML / CSS / JS
          │                       │
          │                   QWebChannel
          │                       │
          └───────────┬───────────┘
                      │
                Python 数据层
                      │
                本地数据存储
```

这种结构使桌宠逻辑与页面交互能够相对独立地开发，同时保持必要的通信与数据共享。

## 💻 从源码运行

### 环境要求

建议使用：

* Windows 10 / 11
* Python 3.13
* Git
* pip

### 1. 克隆仓库

```powershell
git clone https://github.com/meyyy-G/pet-desktop.git

cd pet-desktop
```

### 2. 创建虚拟环境

```powershell
py -3.13 -m venv .venv
```

### 3. 安装依赖

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. 启动程序

```powershell
.\run_app.bat
```

也可以直接运行：

```powershell
.venv\Scripts\python.exe src\desktop_pet_app.py
```

### 关于资源文件

本仓库公开应用源代码和 README 中使用的预览素材，但不包含完整的原创视觉资源。

未公开资源主要包括：

* 桌宠完整动画帧
* 部分 UI 图片
* SVG 图标资源
* Web 字体
* 其他原创视觉素材

相关文件已通过 `.gitignore` 排除。

因此，**仅克隆公开仓库并安装 Python 依赖，可能无法正常还原完整界面或运行程序。**

以上源码运行步骤主要适用于已经具备完整本地资源的开发环境。

普通用户建议直接下载已发布的 Windows 版本。

## 📦 本地打包

PetDesktop 使用 PyInstaller 构建 Windows 可执行程序。

在具备完整私有资源的开发环境中运行：

### 安装开发依赖

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

### 执行打包

```powershell
.\build.bat
```

打包完成后，生成的程序位于：

```text
dist/
└── DesktopPet.exe
```

当前采用 PyInstaller 单文件模式。

`build/` 和 `dist/` 均为本地构建目录，不直接提交至 Git 仓库。

面向用户的可执行程序通过 GitHub Releases 发布。

## 💾 本地数据与隐私

PetDesktop 当前主要采用本地数据存储方式。

日记、心情、桌宠状态和部分应用设置不会自动上传至云端。

### 数据类型

| 数据      | 存储方式                      |
| ------- | ------------------------- |
| 日记内容    | 本地 JSON                   |
| 每日心情    | 本地 JSON                   |
| 桌宠状态    | 本地数据文件                    |
| 桌宠位置与设置 | 本地设置文件                    |
| Home 任务 | Qt WebEngine localStorage |
| Chat 消息 | 当前未持久化                    |

### 默认数据目录

源码运行时，相关 JSON 数据默认保存在项目的：

```text
data/
```

打包后的 Windows 程序默认使用：

```text
%LOCALAPPDATA%\DesktopPet
```

也可以通过环境变量自定义数据目录：

```text
DESKTOP_PET_DATA_DIR
```

### 隐私说明

当前 Chat 页面尚未接入外部 AI 服务。

未来如果接入第三方 AI API，将进一步说明：

* AI 服务提供方
* 对话数据的传输方式
* 数据保存与删除机制
* 相关隐私设置

用户日记与个人数据不应提交到公开 Git 仓库。

PetDesktop 最初从一只简单的桌面小猫开始。

随着时间积累，PetDesktop 不仅保存任务和文字，也能够帮助你回顾自己生活中的点滴。
